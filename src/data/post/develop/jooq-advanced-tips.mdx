## **1. jOOQ는 앞으로 JAVA 11 부터**

Jooq는 **3.15** 부터 Java 11이 요구됩니다.  **[2021.07 release]**

자주 사용되는 jOOQ용 [gradle 플러그인](https://github.com/etiennestuder/gradle-jooq-plugin/releases)도 Java 8을 드랍하고 최소사양이 Java 11 이 되면서

앞으로 jOOQ를 사용하려면 이에 대응해야합니다.

기업용은 8까지 지원하지만, 플러그인에서 지원을 드랍했기 때문에 설정 삽질을 조금 해야할것으로 보이네요.

## **2.  jOOQ DSL에 전용 Prefix  생성**

[[코드 링크]](https://github.com/SightStudio/blog-code/blob/develop/jooq-advanced/jooq-custom/src/main/java/jooq/custom/generator/JPrefixGeneratorStrategy.java)

jOOQ를 통해 생성되는 **DSL**에는 기본 설정 없이는 따로 Prefix가 생성되지 않습니다.

[[QueryDSL](https://github.com/querydsl/querydsl/tree/master/querydsl-sql)]을 사용하셨던 분들은 **"Q + 테이블명" class** 으로 전용 DSL을 사용했던 편리함을 겪으셨을 텐데요.

Jooq에서는 **DefaultGeneratorStrategy**를 상속받음으로써 이를 내가 원하는데로 DSL을 커스텀 할 수 있습니다.

보통 QueryDSL의 Q 클래스처럼 Jooq도 앞에 J를 붙여서 DSL을 만들도록 설정합니다.

![](/images/blog/jooq-advanced-tips/img_2.png)
![](/images/blog/jooq-advanced-tips/img_3.png)
